# Pedidos Parrilla — PWA

Proyecto listo para publicar en GitHub Pages.

## Archivos
- index.html — aplicación corregida
- manifest.webmanifest — instalación como app
- sw.js — funcionamiento offline después de la primera carga
- icon-192.png / icon-512.png — iconos

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube TODOS estos archivos a la raíz del repositorio.
3. En Settings > Pages, selecciona Deploy from a branch.
4. Selecciona la rama `main` y carpeta `/ (root)`.
5. Guarda y espera a que GitHub publique la página.
6. Abre la URL que GitHub Pages te entregue en Chrome en el Xiaomi.
7. En Chrome usa `⋮` > `Añadir a pantalla de inicio` / `Instalar aplicación`.

La aplicación conserva el guardado local de las mesas y productos del dispositivo.
Para compartir los mismos pedidos entre varios teléfonos todavía hace falta una base de datos online.
